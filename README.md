🌍 Eco Travel Advisor Chatbot

An AI-powered conversational chatbot built using Rasa and Streamlit that helps users plan eco-friendly travel itineraries.
The chatbot collects user inputs like destination, budget, travel dates, and preferences, and responds with structured travel guidance using predefined conversation flows and custom actions.

🚀 Features

-Conversational AI built with Rasa framework

-Streamlit-based user interface

-Multi-turn dialogue handling

-Custom Python actions for responses

-Travel planning flow (destination, budget, dates, people)

🛠 Tech Stack

Python 3.9

Rasa 3.6

Streamlit

YAML-based training data

Custom Action Server

💡 Project Goal

To simulate a simple AI travel assistant that helps users plan trips through natural conversation.
